# Documentation Subsystem

## Overview
This directory contains the formal academic reports, literature surveys, architecture blueprints, research gap analyses, and work allocation records for the **Explainable Cloud Identity Risk Assessment for Digital Banking** project.

## Document Directory
1. **[`work_distribution.md`](work_distribution.md):** Detailed responsibilities and milestone allocations for Harika, Ashmit, and Priyanshu.
2. **[`literature_survey.md`](literature_survey.md):** In-depth critical survey of 4 foundational papers (*Hasel Mehri et al., SACMAT '25*, *Rjoub et al., IEEE TNSM '23*, *Jimmy, JAIGS '25*, *Vegas & Llamas, MDPI Future Internet '24*).
3. **[`research_gap.md`](research_gap.md):** Analysis of the critical gap between theoretical explainability models and operational risk scoring in digital banking.
4. **[`architecture.md`](architecture.md):** Formal mathematical formulation of the 5-stage pipeline, continuous risk calibration, and Explanation Graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$.
5. **[`project_documentation.md`](project_documentation.md):** Complete, unified project documentation and review submission report.
