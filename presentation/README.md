# Presentation & Project Review Subsystem

## Purpose
The `presentation/` directory contains slide outlines, evaluation rubrics, architectural talking points, and defense Q&A preparation for academic reviews (Review 1 / Review 2 / Capstone Viva) at **VIT Vellore**.

## Contents
- **[`slide_outline.md`](slide_outline.md):** Slide-by-slide structure with speaker notes covering Title, Problem Statement, Literature Survey, Research Gap, Proposed 5-Stage Architecture, Mathematical Formulation, Prototype Demo, Results, and Future Work.
- **Viva Defense Guide:** Anticipated questions on SHAP attribution complexity, GDPR Art. 22 compliance, latency overheads, and explanation soundness proofs.
